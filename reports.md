### Запланированные задачи
- Обеспечить воспроизводимое развертывание системы с тестовым окружением в виде набора пользователей и таблиц 
- Подготовить прототип связки форм и таблиц с автоматической публикацией данных 
- Реализовать управление пользователями
- Протестировать систему в одновременной работе с несколькими пользователями 
- Подготовить пример таблицы для визуализации рейтинга дисциплины

### Выполненные задачи
- Реализовано воспроизводимое развертывание системы: все необходимые контейнеры с автоматической инициализацией запускаются через CLI, также добавлена команда для наполнения системы тестовыми данными.
- Добавлены скрипты для одиночного и массового создания (по csv файлу) и удаления пользователей.
- Протестированы совместное редактирование несколькими пользователями, выделены особенности работы аудита и режима согласованности данных.
- Реализован прототип связки форм и таблиц, достигнута автоматическая публикация данных.
- Предусмотрена демонстрационная таблица рейтинга дисциплины с автоматическим пересчетом значений с помощью формул.
### Задачи на следующую итерацию
- Формы: доработать сценарий сбора данных, реализовать динамическую привязку форм к таблицам для каждого пользователя
- Адаптер импорта: реализовать модуль загрузки данных из внешних источников (CSV, GitLogger) в систему.
- Резервное копирование: реализовать команды для создания и восстановления резервных копий баз данных.
- Статус: реализовать скрипт проверки состояния всех компонентов системы (статус контейнеров, доступность API, соединение с БД)
- Мониторинг ресурсов: реализовать сбор и отображение метрик нагрузки (CPU, RAM, активные сессии, время отклика)
- Портирование реальных таблиц кафедры: начать миграции имеющихся таблиц на нашу систему
