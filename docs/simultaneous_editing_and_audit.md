# Тестирование одновременной работы нескольких пользователей и функциональности аудита

Дата: 2026-03-17  

Краткое резюме
- Решение было развернуто на сервере и протестировано под реальными условиями: одновременное подключение 3 пользователей к одной таблице.
- При включённой опции `Параметры сервера -> ONLYOFFICE -> Настройки редактора -> Хранить промежуточные версии при редактировании (принудительное сохранение)` аудит (история версий) работает корректно для залогиненных пользователей: после выхода всех редакторов отображается Major-версия с набором Minor-версий, в которых видны изменения каждого пользователя по времени. Без этой опции (по умолчанию на момент формирования отчета) создаются только Major-версии без детализации по пользователям. 
История версий обновляется только после выхода всех редакторов таблицы, в процессе редактирования версии не фиксируются. 
В каждой версии отображается какие конкретно ячейки были изменены.
При необходимости можно восстановить любую версию, она станет новой Major-версией, предыдущие версии не пропадут.
- Изменения файла сохраняются автоматически.
- Одновременное редактирование одной и той же ячейки предотвращается. 
- Изменения других пользователей становятся видимыми мгновенно после освобождения ячейки.
- Вставка изображений, таблиц из других источников работают корректно.
